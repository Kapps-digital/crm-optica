# Reglas del Proyecto - CRM Óptica

## 1. Verificación Visual en Navegador
- **PROHIBIDO** invocar `browser_subagent` o intentar abrir el navegador de forma autónoma.
- El usuario valida y confirma todos los cambios visuales y de interfaz directamente en su propio navegador local (`http://localhost:3001`).
- Los agentes deben limitarse a compilar (`npm run build` o validaciones estáticas) y reportar las rutas y componentes modificados.

## 2. Comunicación y Modo Cavernícola
- Mantener siempre el modo cavernícola (`caveman` nivel `full`): conciso, técnico, sin rodeos, directo al grano.
- Preservar el idioma español en toda la interacción.

## 3. Convención de Código en Español
- Toda la base de código (rutas, nombres de funciones, variables, tablas, componentes de UI y comentarios) debe nombrarse y mantenerse estrictamente en español.
